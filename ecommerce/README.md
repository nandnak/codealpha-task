# CodeAlpha Tasks

## Task 1 - E-commerce Store

A simple full-stack e-commerce web application built using:

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB Atlas

## How to Run

Clone the repository

```bash
git clone https://github.com/nandnak/codealpha-task.git
Install dependencies
npm install

Create .env
Create a .env file using .env.example.

PORT=5000

NODE_ENV=development

MONGODB_URI=your_mongodb_atlas_connection_string

JWT_SECRET=your_jwt_secret_key_here

Add your MongoDB Atlas connection string and other required environment variables.

Start the server
node server.js

Open the website
http://localhost:5000
